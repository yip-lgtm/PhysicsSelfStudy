## 🎯 Project Overview

This is a structured, open-source, self-study project covering:

- **Phase 1 (Year 1):** BSc Physics Foundation (Math Methods, Classical Mechanics, E&M, QM, Statistical Mechanics)
- **Phase 2 (Year 2):** MSc Data-Driven Modeling (ML for Physics, CFD, Quantum Computing, Statistical Inference)
- **Open Source:** All notes, code, and simulations shared publicly for community learning and contribution

**Current Phase:** Phase 1 — BSc Foundation
**Current Course:** PHYS 2124 Mathematical Methods I
**Started:** 2026-06-07

## 🛠️ Tech Stack

### Core Physics
- **Mathematics:** Vector calculus, ODEs, Linear algebra, Complex analysis
- **Numerical Methods:** Finite differences, Finite elements, Monte Carlo
- **Quantum Mechanics:** Schrödinger equation, Perturbation theory

### Tools
- **Python 3.11+** with `numpy`, `scipy`, `sympy`, `qutip`, `matplotlib`, `plotly`
- **Jupyter Notebook** for interactive simulations
- **Anki** for spaced repetition (Physics_BSc_Foundation deck)
- **Git/GitHub** for version control + open source

## 🌍 Open Source — Welcome to Contribute!

This project is **fully open source** under MIT License. Whether you're a:

- 🎓 **Student** — Learn alongside, share notes, ask questions
- 💼 **Practitioner** — Improve simulations, optimize code, add features
- 🔬 **Researcher** — Cite, extend, collaborate on thesis
- 👨‍💻 **Developer** — Add new features, fix bugs, write tests

### How to Contribute

1. **Fork** this repo
2. **Improve** any course material, simulation, or notebook
3. **Submit** a Pull Request with clear description
4. **Open Issues** for bugs, suggestions, or questions

### Areas for Contribution

- ✅ Add more physics simulations (Python + Jupyter)
- ✅ Translate notes to other languages
- ✅ Improve visualizations
- ✅ Write MIT OCW problem solutions
- ✅ Add new courses (e.g., General Relativity, Particle Physics)
- ✅ Create Anki decks for new courses
