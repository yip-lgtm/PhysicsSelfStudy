## 🎯 Learning Objectives

### 1. **Probability Foundations**
- Probability spaces
- Random variables
- Distributions (discrete, continuous)
- Expectation, variance
- Moments, cumulants

### 2. **Stochastic Processes**
- **Poisson processes**
- **Markov chains** (discrete, continuous)
- **Random walks**
- **Brownian motion** (Wiener process)
- **Gaussian processes**

### 3. **Mathematical Tools**
- Conditional expectation
- Martingales
- Stopping times
- Generating functions
- Master equations

### 4. **Applications**
- **Physics:** Diffusion, Langevin dynamics
- **Biology:** Population dynamics, epidemic spreading
- **Finance:** Stock prices, Black-Scholes
- **Engineering:** Queues, reliability
- **ML:** HMM, MCMC, Bayesian inference
