## 📚 Course Information

- **Code:** MSDM 6980
- **Name:** Computational Modeling and Simulation Project
- **University:** HKUST
- **Program:** MSc in Data-Driven Modeling
- **Phase:** 2 (MSc Project)
- **Credits:** 3
- **Note:** Requires course coordinator + supervisor approval

---

## 🎯 Program Overview

Under the **supervision of a faculty member**, students carry out an **independent research project** on computational modeling and simulation.

---

## 🎯 Project Categories

### 1. **Physics Modeling**
- Solid state, condensed matter
- Materials simulation
- Quantum systems

### 2. **Biology/Medicine**
- Drug-target interaction
- Epidemic modeling
- Protein dynamics

### 3. **Engineering/Industry**
- CFD (computational fluid dynamics)
- FEA (finite element)
- Manufacturing processes

### 4. **Data-Driven Methods**
- PINNs (physics-informed neural networks)
- Surrogate modeling
- ML for simulation

---

## 📋 Deliverables

### 1. **Research Output**
- Original work
- Computational implementation
- Validation against data/theory

### 2. **Short Thesis**
- 30-50 pages
- Background, methodology, results
- References

### 3. **Oral Presentation**
- 20-30 min talk
- Q&A session
- Public defense
