## 🎯 Learning Objectives

1. **Advanced Numerical Analysis**
   - Error analysis, stability
   - Condition number
   - Convergence rates

2. **Linear Systems**
   - Direct methods (LU, Cholesky)
   - Iterative methods (CG, GMRES)
   - Preconditioning
   - Sparse matrix techniques

3. **Eigenvalue Problems**
   - Power iteration, Lanczos
   - QR algorithm
   - Singular value decomposition (SVD)
   - Applications in PCA, dimensionality reduction

4. **Optimization**
   - Gradient descent, Newton's method
   - Constrained optimization
   - Lagrange multipliers, KKT conditions
   - Stochastic gradient descent

5. **ODE/PDE Solvers**
   - Implicit methods (backward Euler)
   - Stiff equations
   - Method of lines
   - Finite difference/element for PDEs

6. **Probabilistic Methods**
   - Monte Carlo, MCMC
   - Variational inference
   - Hamiltonian Monte Carlo
   - Applications in Bayesian inference
