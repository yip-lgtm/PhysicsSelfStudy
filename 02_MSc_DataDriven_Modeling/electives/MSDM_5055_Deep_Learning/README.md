## 🎯 Learning Objectives

1. **Neural Network Foundations**
   - Perceptron, MLP
   - Activation functions
   - Backpropagation (manual + autograd)
   - Optimization (SGD, Adam, RMSprop)

2. **Convolutional Neural Networks (CNN)**
   - Convolution, pooling
   - ResNet, VGG, Inception
   - Object detection (YOLO, R-CNN)
   - Semantic segmentation

3. **Recurrent Neural Networks (RNN)**
   - LSTM, GRU
   - Sequence modeling
   - Attention mechanism
   - Applications: time series, NLP

4. **Transformers & Attention**
   - Self-attention, multi-head
   - BERT, GPT architecture
   - Vision Transformer (ViT)
   - Applications across modalities

5. **Generative Models**
   - Variational autoencoders (VAE)
   - Generative adversarial networks (GAN)
   - Diffusion models
   - Normalizing flows

6. **Reinforcement Learning Basics**
   - MDP, Bellman equation
   - Q-learning, DQN
   - Policy gradient
   - Applications in physics/control

7. **Deep Learning for Physics** (advanced)
   - Physics-informed NN
   - Neural operators
   - Equivariant networks
   - Applications to quantum, materials
