## 🎯 Learning Objectives

Optimization and modeling in systems and applications with **many variables and constraints**.

### 1. **Foundations**
- Linear algebra recap
- Convex sets, convex functions
- **Linear programming (LP)**
  - Simplex method
  - Duality
  - Sensitivity analysis
- **Network flow models**
  - Shortest path
  - Max flow, min cut
  - Transportation problem
- **Project management**
  - PERT
  - CPM
  - Critical path

### 2. **Integer Programming**
- Branch and bound
- Cutting planes
- Mixed-integer programming (MIP)

### 3. **Machine Learning Optimization**
- **Support vector algorithms**
- **Kernel methods**
- Convex sets, duality
- Lagrange multipliers
- KKT conditions

### 4. **Optimization Algorithms**
- **1-D optimization** (golden section, bisection)
- **Unconstrained optimization**
  - Gradient descent
  - Newton's method
  - Quasi-Newton (BFGS)
  - Conjugate gradient
- **Guided random search methods**
  - Simulated annealing
  - Genetic algorithms
  - Particle swarm
  - Ant colony
- **Constrained optimization**
  - Penalty methods
  - Barrier methods
  - Augmented Lagrangian

### 5. **Special Topics**
- Stochastic programming
- Robust optimization
- Multi-objective optimization
- Dynamic programming
