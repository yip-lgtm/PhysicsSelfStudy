## 🎯 Learning Objectives

Optimization and modeling in systems and applications with **many variables and constraints**.

### 1. **Foundations**
- Pivot tables
- Linear programming (LP)
- Network flow models
- Project management (PERT/CPM)

### 2. **Machine Learning Optimization**
- Support vector algorithms
- Kernel methods
- Convex sets, duality
- Lagrange multipliers

### 3. **Optimization Algorithms**
- 1-D optimization
- Unconstrained optimization
  - Gradient descent
  - Newton's method
  - Quasi-Newton (BFGS)
  - Conjugate gradient
- **Guided random search methods**
  - Simulated annealing
  - Genetic algorithms
  - Particle swarm
- Constrained optimization
  - Penalty methods
  - Barrier methods
