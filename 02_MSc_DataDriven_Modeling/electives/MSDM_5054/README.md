## 🎯 Learning Objectives

### 1. **Supervised Learning**
- Linear regression
- Classification (logistic regression, SVM, k-NN)
- Tree-based methods (Random Forest, XGBoost, LightGBM)
- Kernel methods (SVM, kernel ridge)

### 2. **Unsupervised Learning**
- Principal Component Analysis (PCA)
- Clustering (k-means, hierarchical, DBSCAN)
- Mixture models (GMM)
- Dimensionality reduction (t-SNE, UMAP)

### 3. **Model Evaluation**
- Cross-validation
- Bias-variance tradeoff
- Regularization (L1, L2, elastic net)
- Hyperparameter tuning

### 4. **Practical Skills**
- **R or Python** implementation
- Apply to real data analysis
- Industry-relevant workflows
