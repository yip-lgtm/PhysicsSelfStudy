## 🎯 Learning Objectives

### 1. **Fundamental Concepts**
- Strict stationarity
- Weak stationarity
- Series correlation
- Autocorrelation function (ACF)
- Partial autocorrelation (PACF)

### 2. **Classical Time Series Models**
- **Autoregressive (AR) model**
- **Moving Average (MA) model**
- **ARMA model**
- **Seasonal ARIMA (SARIMA)**
- **Multivariate time series** (VAR, VMA)

### 3. **Financial Time Series Models**
- **ARCH** (Autoregressive Conditional Heteroskedasticity)
- **GARCH** (Generalized ARCH)
- EGARCH, GJR-GARCH
- Volatility modeling

### 4. **Forecasting Techniques**
- Based on time series models
- Model evaluation (AIC, BIC, cross-validation)
- Real-world applications:
  - Natural science data
  - Engineering data
  - Economics data

### 5. **Modern Approaches (intro)**
- State-space models
- Kalman filter
- RNN/LSTM for time series
- Transformer-based forecasting
