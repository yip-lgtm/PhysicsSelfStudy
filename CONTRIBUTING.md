# 🤝 CONTRIBUTING — How to Contribute

> **PhysicsSelfStudy is open-source and community-driven.**
> We welcome contributions from learners, educators, and researchers.

---

## 🌟 Why Contribute?

- 🎓 **Help others learn** — your notes could save someone weeks of confusion
- 🏆 **Build your portfolio** — visible contributions to an open-source project
- 🌍 **Join a community** — connect with physics learners worldwide
- 📈 **Improve your understanding** — teaching is the best way to learn

---

## 🚀 Quick Start

### 1. Fork the repository

Click the **Fork** button on the [GitHub repo](https://github.com/yip-lgtm/PhysicsSelfStudy).

### 2. Clone your fork

```bash
git clone https://github.com/YOUR_USERNAME/PhysicsSelfStudy.git
cd PhysicsSelfStudy
```

### 3. Create a branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make your changes

### 5. Commit with a clear message

```bash
git commit -m "Add: Week 2 notebook for differential equations"
```

### 6. Push and create a Pull Request

```bash
git push origin feature/your-feature-name
```

Then open a Pull Request on GitHub.

- Add weekly reflections

- Translate READMEs to other languages (中文, 日本語, etc.)

## 📂 Project Structure Guidelines

### Where to add what

| Content | Location |
|---------|----------|
| Course-specific content | `XX_Phase/folder/PHYS_CODE_Course_Name/` |
| Code/simulations | `portfolio_projects/simulations/` |
| Jupyter notebooks | `portfolio_projects/notebooks/` |
| Visualizations | `portfolio_projects/visualizations/` |
| MIT OCW solutions | `portfolio_projects/mit_ocw/` |
| Weekly reflections | `weekly_reflections/YYYY-MM-DD.md` |
| Anki decks | `Anki_decks/` |
| Resources | `resources/` |

### File naming conventions

- **Course folders:** `PHYS_<code>_<Name_with_underscores>`
- **Notebooks:** `WeekXX_<Topic>.ipynb` or `WeekXX_<Topic>.py`
- **Reflections:** `YYYY-MM-DD.md` (use today's date)
- **Images:** `descriptive_name.png` (lowercase, underscores)

## 📝 README Contribution Guidelines

When adding to a course README, include:

1. **Course Information** — code, name, university, credits
2. **Learning Objectives** — bullet points
3. **Topics Covered** — week-by-week breakdown if applicable
4. **Resources** — textbooks, MIT OCW, papers
5. **Project Ideas** — concrete project suggestions
6. **Self-Study Tips** — what worked for you

### README template

```markdown
# <Code> — <Name> (<University>)

> <Tagline + Phase>

---

## 📚 Course Information

- **Code:** <code>
- **Name:** <name>
- **University:** <univ>
- **Program:** <program>
- **Phase:** <phase>
- **Credits:** <credits>

---

## 🎯 Learning Objectives

### 1. <Topic>
- <Objective>
- <Objective>

---

## 📖 Resources

### Primary
- <Textbook 1>
- <Textbook 2>

---

## 🎯 Project Ideas

- <Project 1>
- <Project 2>

---

*Last updated: <date>*
```

## 🐍 Code Style

### Python
- Follow **PEP 8**
- Use **type hints** where appropriate
- Add **docstrings** to functions
- Include **comments** for complex math
- Test your code before submitting

### Jupyter Notebooks
- Clear markdown cells explaining each step
- Code cells should be runnable top-to-bottom
- Include output/plots in the notebook
- Add a brief intro and conclusion
