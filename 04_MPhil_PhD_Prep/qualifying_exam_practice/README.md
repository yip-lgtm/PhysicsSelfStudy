## 🎯 QE Overview

The **Qualifying Exam** is typically taken in **Year 1-2 of PhD program**. It tests:

- Core physics (Classical, EM, QM, StatMech)
- Research aptitude
- Problem-solving skills

---

## 📚 Core Topics

### Classical Mechanics
- Lagrangian / Hamiltonian formulations
- Central force, oscillations, rigid body

### Electromagnetism
- Maxwell equations
- EM waves, radiation
- Boundary value problems

### Quantum Mechanics
- Schrödinger equation
- Hydrogen atom
- Angular momentum, spin
- Perturbation theory

### Statistical Mechanics
- Ensembles
- Phase transitions
- Critical phenomena
