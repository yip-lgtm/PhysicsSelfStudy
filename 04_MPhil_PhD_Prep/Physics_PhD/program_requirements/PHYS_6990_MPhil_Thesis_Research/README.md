## 📋 MPhil Thesis Structure

Typical MPhil thesis (40-80 pages):
- Abstract (300 words)
- Introduction (background + significance)
- Literature Review
- Methodology
- Results
- Discussion
- Conclusion + Future Work
- References (Harvard format)
