---

## 📋 MPhil Thesis Structure (Nano Sci & Tech)

Typical MPhil thesis (40-80 pages):
- Abstract (300 words)
- Introduction (background + significance)
- Literature Review
- Methodology (synthesis, characterization, fabrication)
- Results
- Discussion
- Conclusion + Future Work
- References (Harvard format)
