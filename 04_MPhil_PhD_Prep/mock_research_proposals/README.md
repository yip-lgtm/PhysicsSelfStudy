## 📋 Proposal Format

A typical research proposal is **3-5 pages** with:

1. **Title**
2. **Abstract** (200 words)
3. **Introduction** (background + significance)
4. **Literature Review** (5-10 key papers)
5. **Research Question / Hypothesis**
6. **Methodology** (theory / experiment / simulation)
7. **Expected Outcomes**
8. **Timeline** (3-4 years)
9. **References** (Harvard format)
