## 🎯 Learning Objectives

1. **Standard Cosmological Model**
   - Friedmann equations
   - Cosmological redshift
   - Hubble parameter
   - Age of the universe

2. **Early Universe**
   - Big Bang nucleosynthesis
   - Recombination
   - Cosmic microwave background (CMB)

3. **Inflation**
   - Horizon problem
   - Slow-roll inflation
   - Density perturbations
   - CMB anisotropies

4. **Dark Sector**
   - Dark matter evidence
   - Dark energy
   - ΛCDM model

5. **Observational Cosmology**
   - Type Ia supernovae
   - Baryon acoustic oscillations
   - CMB observations (Planck, WMAP)
