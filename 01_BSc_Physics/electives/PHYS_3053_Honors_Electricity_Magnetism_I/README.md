## 🎯 Learning Objectives

Same as **PHYS 3033 E&M I** but with:

1. **Advanced mathematical methods**
   - Tensor analysis
   - Green's functions (advanced)
   - Multipole expansions (full treatment)
   - Boundary value problems (advanced methods)

2. **Special relativity (preview)**
   - 4-vectors
   - Covariant formulation of E&M
   - Lorentz transformations

3. **Selected Jackson topics**
   - Waveguides (intro)
   - Cavity resonators (intro)
   - Scattering (intro)
