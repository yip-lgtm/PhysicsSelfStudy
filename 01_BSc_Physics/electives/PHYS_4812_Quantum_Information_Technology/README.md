## 🎯 Learning Objectives

1. **Quantum Computing Hardware**
   - Superconducting qubits
   - Trapped ions
   - Photonic quantum computing
   - Topological qubits

2. **Quantum Algorithms**
   - Deutsch-Jozsa
   - Grover's search
   - Shor's factoring
   - Quantum simulation

3. **Quantum Cryptography**
   - BB84 protocol
   - Quantum key distribution
   - E91 protocol

4. **Quantum Error Correction**
   - Bit-flip, phase-flip codes
   - Shor code
   - Surface codes

5. **Current State-of-Art**
   - IBM Q, Google Sycamore
   - Quantum supremacy
   - NISQ era algorithms
