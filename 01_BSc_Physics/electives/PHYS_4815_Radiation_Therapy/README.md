## 🎯 Learning Objectives

1. **Radiation Physics**
   - X-ray production
   - Megavoltage beams (linac, Co-60)
   - Particle therapy (protons, carbon ions)
   - Brachytherapy

2. **Radiation Interactions**
   - Photoelectric effect
   - Compton scattering
   - Pair production
   - Linear energy transfer (LET)

3. **Dosimetry**
   - Dose definitions
   - Ion chambers
   - Thermoluminescent dosimeters (TLD)
   - Monte Carlo dose calculation

4. **Treatment Planning**
   - IMRT, VMAT
   - Image-guided RT
   - 4D CT
   - Inverse planning

5. **Radiobiology**
   - Cell survival curves
   - Linear-quadratic model
   - Fractionation
   - Normal tissue effects
