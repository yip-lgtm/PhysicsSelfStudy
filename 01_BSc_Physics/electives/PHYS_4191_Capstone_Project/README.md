## 🎯 Project Components

1. **Topic Selection** (Week 1-2)
   - Choose with supervisor
   - Define research question
   - Set milestones

2. **Literature Review** (Weeks 3-4)
   - Survey 10-20 key papers
   - Identify knowledge gap
   - Write review document

3. **Project Plan** (Week 5)
   - Methodology
   - Timeline
   - Resources needed

4. **Execution** (Weeks 6-20)
   - Run simulations / experiments
   - Weekly meetings with supervisor
   - Mid-term progress report

5. **Final Deliverables**
   - Final report (20-30 pages)
   - Oral presentation (15-20 min)
   - Code/data repository
