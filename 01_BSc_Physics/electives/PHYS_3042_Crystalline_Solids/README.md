## 🎯 Learning Objectives

1. **Crystal Structure**
   - Bravais lattices
   - Miller indices
   - Reciprocal lattice
   - X-ray diffraction

2. **Lattice Dynamics**
   - Phonons
   - Specific heat (Einstein, Debye models)
   - Thermal conductivity

3. **Free Electron Gas**
   - Drude model
   - Sommerfeld model
   - Electrical conductivity

4. **Band Structure**
   - Bloch theorem
   - Nearly-free electron model
   - Tight-binding model
   - Semiconductors

5. **Semiconductor Physics**
   - Intrinsic and extrinsic
   - p-n junctions
   - Transistors
