## 🎯 Learning Objectives

1. **Observational Astronomy**
   - Telescopes
   - Coordinate systems
   - Magnitude, parallax

2. **Stellar Physics**
   - Hydrostatic equilibrium
   - Nuclear reactions
   - Stellar atmospheres
   - Stellar spectra

3. **Stellar Evolution**
   - Main sequence
   - Red giants
   - White dwarfs, neutron stars
   - Supernovae

4. **Stellar Systems**
   - Binary stars
   - Star clusters
   - Milky Way structure
