## 🎯 Learning Objectives

Same as **PHYS 3036 QM I** but with:

1. **Deeper mathematical treatment**
   - Functional analysis background
   - Rigorous proof of spectral theorem
   - Group theory applications (SU(2), rotation group)

2. **More advanced problem sets**
   - Mathematical derivations from scratch
   - Open-ended problems
   - Original research-style questions

3. **Additional topics**
   - Density matrices
   - EPR / Bell inequalities (preview)
   - Path integral formulation (intro)
