## 🎯 Learning Objectives

1. **Linear ODEs (Advanced)**
   - Existence and uniqueness theorems
   - Wronskian
   - Variation of parameters (rigorous)

2. **Systems of ODEs**
   - Matrix form
   - Eigenvalue analysis
   - Phase portraits
   - Stability

3. **Series Solutions**
   - Ordinary and singular points
   - Frobenius method (full)
   - Bessel, Legendre, Hermite equations

4. **Laplace Transforms**
   - Definition, properties
   - Solving initial value problems
   - Convolution

5. **Partial Differential Equations (intro)**
   - Heat equation
   - Wave equation
   - Laplace's equation
   - Separation of variables
