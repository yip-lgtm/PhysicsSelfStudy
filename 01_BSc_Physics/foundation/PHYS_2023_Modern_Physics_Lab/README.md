## 🎯 Learning Objectives

Companion laboratory course to PHYS 2022. Hands-on experiments in modern physics.

### Typical Experiments

1. **Atomic Physics**
   - Hydrogen spectrum (spectrometer)
   - Sodium doublet
   - Zeeman effect
   - Franck-Hertz experiment

2. **Quantum Effects**
   - Photoelectric effect (h measurement)
   - Electron diffraction (de Broglie)
   - Millikan oil drop (e measurement)
   - Compton scattering

3. **Nuclear Physics**
   - Geiger-Müller counter
   - Radioactive decay (Po, Cs, Co)
   - Half-life measurement
   - Absorption of gamma rays
   - Neutron activation (if available)

4. **Solid State**
   - Hall effect
   - Band gap (semiconductor)
   - X-ray diffraction (powder)

5. **Data Analysis**
   - Error analysis
   - Curve fitting
   - Statistics
