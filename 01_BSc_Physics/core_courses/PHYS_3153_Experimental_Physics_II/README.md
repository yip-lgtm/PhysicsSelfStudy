## 🎯 Learning Objectives

1. **Advanced Measurement Techniques**
   - Lock-in amplifiers
   - Fourier transform spectroscopy
   - Interferometry
   - Microscopy (optical, electron, AFM)

2. **Vacuum Technology**
   - Low/ultra-high vacuum
   - Pumps, gauges
   - Thin-film deposition

3. **Electronics for Physicists**
   - Op-amps, filters
   - Noise analysis
   - Data acquisition (DAQ)
   - Microcontrollers (Arduino, Raspberry Pi)

4. **Modern Physics Experiments**
   - Muon lifetime
   - Franck-Hertz
   - Electron spin resonance (ESR)
   - Nuclear magnetic resonance (NMR)

5. **Research-Style Project**
   - Open-ended experimental design
   - 1-month extended project
   - Conference-style presentation
