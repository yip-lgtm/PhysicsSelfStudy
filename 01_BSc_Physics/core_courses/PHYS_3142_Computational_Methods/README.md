## 🎯 Learning Objectives

1. **Numerical Methods**
   - Root finding (Newton-Raphson, bisection)
   - Interpolation and extrapolation
   - Numerical integration (Simpson, Gauss)
   - ODE solvers (Euler, RK4, leapfrog)

2. **Linear Algebra Computations**
   - Matrix operations
   - Eigenvalue problems
   - Solving linear systems
   - SVD and applications

3. **Monte Carlo Methods**
   - Random number generation
   - Monte Carlo integration
   - Metropolis algorithm
   - Applications in statistical physics

4. **Simulations**
   - N-body simulations
   - Molecular dynamics (Lennard-Jones)
   - Lattice models (Ising)
   - Cellular automata

5. **Data-Driven Physics**
   - Curve fitting
   - Fourier analysis
   - Wavelet transforms
   - Machine learning basics

## 🗓️ Week-by-Week Plan

### Week 1-2: Numerical Foundations
- Floating point, error analysis
- Root finding, interpolation
- Numerical integration

### Week 3-4: ODE Solvers
- Euler, RK4
- Leapfrog (symplectic)
- Adaptive step size
- Boundary value problems

### Week 5-6: Linear Algebra
- Matrix decompositions
- Eigenvalue problems
- Applications: coupled oscillators, normal modes

### Week 7-8: Monte Carlo & MD
- Random number generators
- Monte Carlo integration
- Molecular dynamics
- Ising model
