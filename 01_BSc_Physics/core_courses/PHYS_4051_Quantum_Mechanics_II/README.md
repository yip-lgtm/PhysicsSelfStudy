## 🎯 Learning Objectives

1. **Perturbation Theory**
   - Time-independent (non-degenerate, degenerate)
   - Fine structure of hydrogen
   - Zeeman effect
   - Stark effect

2. **Variational Method**
   - Ground state energy bounds
   - Helium atom
   - Hydrogen molecule ion

3. **WKB Approximation**
   - Semiclassical limit
   - Tunneling corrections
   - Connection formulas

4. **Time-Dependent Perturbation Theory**
   - Fermi's golden rule
   - Harmonic perturbation
   - Selection rules

5. **Scattering Theory**
   - Partial wave analysis
   - Born approximation
   - Phase shifts

6. **Identical Particles**
   - Symmetrization
   - Exchange interaction
   - Band structure (intro)

7. **Relativistic QM (intro)**
   - Klein-Gordon equation
   - Dirac equation
   - Spinors
