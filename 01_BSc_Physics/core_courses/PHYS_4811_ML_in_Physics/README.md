## 🎯 Learning Objectives

1. **ML Foundations**
   - Supervised vs unsupervised learning
   - Regression, classification
   - Neural networks (MLP, CNN, RNN)
   - Training, validation, testing

2. **Physics-Informed ML**
   - Physics-Informed Neural Networks (PINN)
   - Physics-informed Gaussian processes
   - Loss functions with PDE constraints
   - Applications to Schrödinger, Navier-Stokes

3. **ML for Quantum Systems**
   - Neural network quantum states
   - Variational Monte Carlo
   - Quantum machine learning
   - Restricted Boltzmann machines

4. **ML for Materials**
   - Crystal property prediction
   - Potential energy surfaces
   - Materials informatics
   - Graph neural networks for molecules

5. **Generative Models for Physics**
   - Variational autoencoders
   - Normalizing flows
   - Diffusion models
   - Applications: phase transitions, lattice QCD
