## 🎯 Learning Objectives

1. **Classical Thermodynamics**
   - Laws of thermodynamics
   - Thermodynamic potentials
   - Phase equilibria
   - Chemical reactions

2. **Kinetic Theory**
   - Maxwell-Boltzmann distribution
   - Mean free path
   - Transport phenomena
   - Brownian motion

3. **Statistical Mechanics (Microcanonical)**
   - Phase space, ergodicity
   - Liouville's theorem
   - Microcanonical ensemble

4. **Statistical Mechanics (Canonical, Grand Canonical)**
   - Canonical ensemble
   - Partition function
   - Grand canonical ensemble
   - Quantum statistics

5. **Applications**
   - Ideal gas
   - Black-body radiation
   - Bose-Einstein condensation
   - Fermi gas

6. **Phase Transitions**
   - Ising model
   - Mean-field theory
   - Critical phenomena
   - Renormalization group (intro)
