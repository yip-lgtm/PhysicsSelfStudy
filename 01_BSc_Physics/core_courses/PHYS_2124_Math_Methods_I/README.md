## 🎯 Learning Objectives

By the end of this course, you should be able to:

1. **Vector Calculus**
   - Perform dot, cross products
   - Compute gradient, divergence, curl
   - Apply Stokes' theorem, divergence theorem
   - Visualize vector fields

2. **Ordinary Differential Equations (ODEs)**
   - Solve first-order ODEs (separable, linear, exact)
   - Solve second-order linear ODEs
   - Apply ODEs to physics problems (oscillations, decay)
   - Implement Euler, RK4 in Python

3. **Linear Algebra**
   - Matrix operations, determinants
   - Eigenvalues, eigenvectors
   - Solve linear systems
   - Applications to coupled oscillators, QM

4. **Complex Analysis**
   - Complex numbers, functions
   - Contour integration
   - Residue theorem
   - Fourier transforms

## 🗓️ Week-by-Week Plan

### Week 1: Vector Calculus (Foundation)
- **Theory:** Vectors, dot/cross product, gradient
- **Problems:** 5-8 from MIT OCW 18.02
- **Coding:** Vector operations toolkit (numpy)
- **Deliverable:** `Week01_Vector_Calculus_Toolkit.py` ✅ (already done!)

### Week 2: Vector Calculus (Advanced)
- **Theory:** Divergence, curl, line/surface integrals
- **Problems:** Stokes' theorem, divergence theorem
- **Coding:** Vector field visualization (matplotlib)

### Week 3: ODEs (First-Order)
- **Theory:** Separable, linear, exact ODEs
- **Problems:** Exponential decay, population dynamics
- **Coding:** Euler method implementation

### Week 4: ODEs (Second-Order)
- **Theory:** Linear ODEs with constant coefficients
- **Problems:** Harmonic oscillator, damped/forced
- **Coding:** RK4 method, oscillator simulation

### Week 5: Linear Algebra
- **Theory:** Matrices, determinants, eigenvalues
- **Problems:** Matrix manipulation, eigenvalue problems
- **Coding:** Matrix toolkit with numpy

### Week 6: Linear Algebra Applications
- **Theory:** Coupled oscillators, normal modes
- **Problems:** Eigenvalue physics problems
- **Coding:** Coupled oscillator simulation

### Week 7: Complex Analysis
- **Theory:** Complex numbers, functions
- **Problems:** Complex integration
- **Coding:** Complex visualization

### Week 8: Final Review + Project
- **Theory:** Comprehensive review
- **Project:** Solve a physics problem using all methods
- **Deliverable:** Final course report
