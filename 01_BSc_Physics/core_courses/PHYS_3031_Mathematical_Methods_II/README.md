## 🎯 Learning Objectives

1. **Linear Algebra (Advanced)**
   - Vector spaces, basis
   - Linear operators
   - Inner products
   - Spectral theorem

2. **ODEs (Advanced)**
   - Series solutions
   - Frobenius method
   - Special functions (Legendre, Bessel, Hermite)

3. **PDEs (Introduction)**
   - Separation of variables
   - Sturm-Liouville theory
   - Eigenfunction expansions
   - Green's functions

4. **Complex Analysis (Advanced)**
   - Cauchy's integral theorem
   - Residue theorem
   - Laurent series
   - Conformal mapping

5. **Fourier Analysis**
   - Fourier series
   - Fourier transforms
   - Laplace transforms
   - Applications to PDEs
