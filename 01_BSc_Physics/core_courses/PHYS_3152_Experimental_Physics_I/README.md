## 🎯 Learning Objectives

1. **Data Analysis & Statistics**
   - Error analysis
   - Probability distributions
   - Least-squares fitting
   - Chi-squared test

2. **Measurement Techniques**
   - Precision instruments
   - Calibration
   - Signal-to-noise optimization

3. **Sensors & Detectors**
   - Photodiodes, photomultipliers
   - CCD cameras
   - Particle detectors
   - Cryogenics (intro)

4. **Lab Experiments**
   - Optical spectroscopy
   - Magnetic measurements
   - Electrical measurements
   - Modern physics experiments

5. **Report Writing**
   - Scientific writing
   - Lab notebook maintenance
   - Uncertainty quantification
