## 🎯 Learning Objectives

1. **Geometric Optics**
   - Reflection, refraction
   - Mirrors, lenses
   - Optical instruments

2. **Wave Optics**
   - Interference (Young's double-slit, Michelson)
   - Diffraction (single slit, gratings)
   - Coherence

3. **Polarization**
   - Linear, circular, elliptical
   - Malus's law
   - Brewster's angle
   - Birefringence

4. **Modern Optics**
   - Lasers (intro)
   - Fiber optics (intro)
   - Nonlinear optics (intro)
