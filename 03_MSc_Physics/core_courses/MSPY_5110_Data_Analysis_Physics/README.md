## 🎯 Learning Objectives

### 1. **Statistical Foundations**
- Probability distributions (Binomial, Poisson, Gaussian, chi-square, t, F)
- Bayesian inference
- Error analysis (propagation, systematic, statistical)
- Hypothesis testing
- Maximum likelihood estimation

### 2. **Data Analysis Tools**
- **Python** (NumPy, SciPy, pandas, Matplotlib)
- R (overview)
- **ROOT** (high-energy physics)
- Jupyter notebooks

### 3. **Techniques for Physics Data**
- **Curve fitting** (least-squares, MLE, chi-square)
- **Monte Carlo methods** (rejection, importance sampling)
- **Signal processing** (FFT, filtering, convolution)
- **Image analysis** (edge detection, segmentation)
- **Time series analysis**

### 4. **Modern Approaches**
- Machine learning basics (linear, tree-based)
- Neural networks for physics
- Bayesian data analysis
- **MCMC** (Markov Chain Monte Carlo)
- Gaussian processes
