## 🎯 Learning Objectives

### 1. **Mechanical Properties**
- Stress, strain (tensorial)
- Elasticity, plasticity
- Dislocations, deformation
- Fracture mechanics
- Hardness, fatigue, creep

### 2. **Thermal Properties**
- Heat capacity
- Thermal conductivity
- Thermal expansion
- Phase transitions
- Thermodynamics of materials

### 3. **Electrical Properties**
- Conductors, insulators, semiconductors
- Dielectric properties
- Piezoelectricity
- Superconductivity (intro)
- Ionic conductivity

### 4. **Magnetic Properties**
- Diamagnetism, paramagnetism
- Ferromagnetism
- Antiferromagnetism
- Ferrimagnetism
- Magnetic domains
- Magnetostriction

### 5. **Optical Properties**
- Reflection, refraction
- Absorption, emission
- Luminescence, fluorescence
- Plasmonics
- Nonlinear optics

### 6. **Structure-Property Relationships**
- Atomic bonding → properties
- Crystal structure → properties
- Defects → properties
- Microstructure → properties
