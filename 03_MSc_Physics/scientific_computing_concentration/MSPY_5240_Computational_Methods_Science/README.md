## 🎯 Learning Objectives

### 1. **Numerical Methods**
- Linear systems (direct, iterative)
- Eigenvalue problems
- ODEs (initial value, boundary value)
- PDEs (FD, FE, FV)

### 2. **Optimization**
- Linear programming
- Nonlinear programming
- Constrained optimization
- Stochastic optimization

### 3. **Statistical Methods**
- MCMC
- Bayesian inference
- Bootstrap, jackknife
- Cross-validation

### 4. **Signal Processing**
- FFT, wavelets
- Filtering
- Image processing
- Time-frequency analysis

### 5. **Applications in Physics**
- Schrödinger equation solver
- Maxwell solver
- Diffusion-reaction
- Molecular dynamics
- Quantum Monte Carlo
