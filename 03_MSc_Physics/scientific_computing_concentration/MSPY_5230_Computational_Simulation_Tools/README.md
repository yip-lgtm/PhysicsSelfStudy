## 🎯 Learning Objectives

### 1. **Linux & HPC**
- Linux environment
- Shell scripting
- HPC cluster usage
- Job scheduling (SLURM)

### 2. **Programming Tools**
- **Python** (primary)
- C/C++ for performance
- Fortran (legacy)
- Julia (modern)

### 3. **Numerical Libraries**
- NumPy, SciPy
- Matplotlib, Plotly
- SymPy (symbolic)
- petsc4py (parallel)

### 4. **Simulation Software**
- Molecular dynamics (LAMMPS, GROMACS)
- DFT (Quantum ESPRESSO, VASP)
- Monte Carlo
- Finite element (FEniCS, COMSOL)

### 5. **Workflow Tools**
- Version control (Git)
- Build systems (Make, CMake)
- Documentation (Sphinx)
- Container (Docker, Singularity)
