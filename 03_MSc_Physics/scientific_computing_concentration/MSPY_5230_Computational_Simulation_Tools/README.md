## 🎯 Learning Objectives

### 1. **Linux & HPC**
- Linux environment
- Shell scripting (bash)
- HPC cluster usage
- **Job scheduling (SLURM)**
- Module system

### 2. **Programming Tools**
- **Python** (primary)
- C/C++ for performance
- Fortran (legacy scientific code)
- Julia (modern, high-perf)
- GPU programming (CUDA, OpenCL intro)

### 3. **Numerical Libraries**
- **NumPy, SciPy**
- **Matplotlib, Plotly**
- **SymPy** (symbolic)
- **petsc4py** (parallel)
- MPI for distributed computing

### 4. **Simulation Software**

#### Molecular Dynamics
- **LAMMPS**
- **GROMACS**
- NAMD

#### DFT / Electronic Structure
- **Quantum ESPRESSO**
- **VASP**
- CP2K, Abinit, SIESTA

#### Monte Carlo
- Spin MC
- Lattice MC
- Classical MC

#### Finite Element
- **FEniCS**
- **COMSOL**
- FreeFEM++

### 5. **Workflow Tools**
- Version control (**Git**)
- Build systems (**Make, CMake**)
- Documentation (Sphinx)
- Container (**Docker, Singularity**)
- CI/CD (GitHub Actions)
