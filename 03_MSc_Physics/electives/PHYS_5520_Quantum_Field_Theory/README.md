## 🎯 Learning Objectives

### 1. **Special Relativity + Classical Fields**
- Lorentz transformations
- 4-vectors, 4-tensors
- Relativistic kinematics
- Lagrangian field theory

### 2. **Canonical Quantization of Fields**
- Real scalar field
- Complex scalar field
- Fock space
- Creation + annihilation operators
- Propagators

### 3. **Path Integral Formulation**
- Functional integration
- Generating functionals
- Perturbation theory
- Feynman diagrams
- Feynman rules

### 4. **Fermions**
- Dirac field
- Spinor representations
- Quantization of Dirac field
- Grassmann variables
- Anticommutation relations

### 5. **Quantum Electrodynamics (QED)**
- Gauge invariance
- Photon field
- Interaction Lagrangian
- Tree-level processes
- Cross sections

### 6. **Renormalization (intro)**
- Divergences
- Dimensional regularization
- Renormalization group
- Beta functions
