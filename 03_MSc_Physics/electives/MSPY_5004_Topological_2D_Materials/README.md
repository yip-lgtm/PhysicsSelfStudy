## 🎯 Learning Objectives

### 1. **2D Materials**
- **Graphene** (Dirac cones, Klein tunneling)
- **Transition metal dichalcogenides** (MoS2, WSe2)
- **Black phosphorus**
- **Hexagonal boron nitride (hBN)**
- **2D magnets**
- **Heterostructures** (twistronics, magic angle)

### 2. **Topological Materials**
- **Topological insulators** (2D, 3D)
- **Weyl semimetals**
- **Dirac semimetals**
- **Topological superconductors**
- **Chern insulators**
- **Quantum spin Hall effect**
- **Majorana fermions**

### 3. **Synthesis & Characterization**
- **CVD growth** of graphene, TMDs
- **Mechanical exfoliation**
- **MBE** (molecular beam epitaxy)
- **STM/AFM** characterization
- **ARPES** for band structure
- **Transport measurements**

### 4. **Applications**
- **Electronics** (transistors, RF)
- **Spintronics**
- **Quantum computing** (topological qubits)
- **Optoelectronics** (photodetectors, LEDs)
- **Sensors**
- **Energy** (batteries, supercapacitors)
