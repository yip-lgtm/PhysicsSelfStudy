## 🎯 General

### What is PhysicsSelfStudy?

A **structured 24+ month self-study program** that takes you from foundational physics to research-level mastery, aligned with the **HKUST (Hong Kong University of Science and Technology)** curriculum. The project is open-source and MIT licensed.

### Who is this for?

- 🎓 **Self-learners** wanting university-level physics
- 🧑‍💻 **Programmers** transitioning to physics/data science
- 🔬 **Researchers** preparing for MPhil/PhD applications
- 🌏 **Hong Kong Web3/AI/Physicist** community members
- 📚 **Educators** looking for a structured curriculum

### Is this affiliated with HKUST?

**No, this is an independent project.** However, the curriculum is **aligned with HKUST's official course catalog** for the academic year 2025-2026. Course codes, names, and credit values match HKUST's published catalog.

## 📚 Curriculum

### How long does it take to complete?

- **Phase 1 (BSc):** ~18 months (weekend-only)
- **Phase 2 (MSc DM):** ~12 months
- **Phase 3 (MSc Physics):** ~12 months
- **Phase 4 (PhD Prep):** ~6-12 months
- **Total:** 24-54 months depending on pace

### Can I skip courses?

Yes, especially in the BSc electives. The core courses (especially the 13 main core + math support) are essential. You can choose which electives and which MSc concentration to pursue.

### Can I start with a different phase?

Yes! If you have a strong physics background, you can start at Phase 2 or 3. If you're a complete beginner, start at Phase 1 with `PHYS 1001` or `PHYS 1111`.

### What's the difference between the two MSc programs?

- **MSc Data-Driven Modeling:** Focuses on **computational + ML** applications in physics/science
- **MSc Physics:** Traditional physics with two concentrations:
  - **Advanced Materials** (semiconductor, materials, experimental)
  - **Scientific Computing** (simulation, AI in science)

You can do both! Or pick one. They're complementary.

### What if I want to do a PhD, not MSc?

Go straight to **Phase 4 (MPhil/PhD Prep)**. But we recommend at least an MSc first for research experience.

## 🛠️ Setup & Tools

### What tools do I need?

**Required:**
- Computer (Mac, Linux, Windows)
- Python 3.9+
- Git + GitHub account
- Text editor (VS Code recommended)

**Recommended:**
- Jupyter Notebook
- LaTeX (for writing papers)
- Anki (spaced repetition)
- OpenClaw (or other automation tool)

### How do I set up Python?

See [`resources/python_env_setup.md`](resources/python_env_setup.md) for detailed instructions.

Quick start:
```bash
python3 -m venv venv
source venv/bin/activate
pip install numpy scipy matplotlib pandas jupyter sympy
```

### Can I use a different language than Python?

Yes! PhysicsSelfStudy uses Python for examples, but you can do the projects in:
- **Julia** (for high-performance computing)
- **C/C++** (for performance-critical code)
- **MATLAB** (industry standard in some fields)
- **Mathematica** (symbolic math)

## 📅 Schedule

### Why weekend-only?

The 8.5 hours/weekend schedule is designed to be sustainable alongside full-time work or study. It's a marathon, not a sprint.

### What if I miss a weekend?

No problem! Life happens. Just resume the next weekend. The schedule is flexible.

### Can I do more than 8.5h?

Absolutely! 8.5h is the **minimum** commitment. If you can do more, you'll finish faster. Just don't burn out.

### What are the 4 cron rules?

1. **Saturday Theory Block** — 4h (9am-1pm HKT)
2. **Sunday Computational Sprint** — 4h (2pm-6pm HKT)
3. **Sunday Weekly Review** — 30min (7pm HKT)
4. **Monthly Milestone Review** — 1h (1st Sun of month, 8pm HKT)

See `cron_examples.md` for setup.

## 🎓 Career & Applications

### Will this get me into HKUST MPhil/PhD?

**Not directly.** This is a self-study program. To apply for MPhil/PhD, you need:
- Bachelor's degree (or equivalent)
- Research experience (papers, projects)
- Recommendation letters
- Statement of purpose
- GRE/TOEFL scores (if required)

**What this program DOES:**
- ✅ Build foundational knowledge equivalent to BSc
- ✅ Develop research skills via projects
- ✅ Provide PhD application prep (Phase 4)

### What jobs can I get with this knowledge?

- 🔬 **Research scientist** (industry, national labs)
- 🤖 **ML/AI engineer** (with Phase 2)
- 💻 **Quantitative researcher** (finance, trading)
- ⚛️ **Physics R&D** (semiconductor, materials, energy)
- 📊 **Data scientist** (any industry)
- 🎓 **Academia** (with PhD)

### Is this recognized by employers?

**The knowledge is.** The repo itself is a portfolio piece, but employers care more about your skills and projects than any specific certification. Build cool things, contribute to open source, and the rest follows.
